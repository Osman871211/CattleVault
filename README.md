# 🐄 CattleVault — Cow Business E-Commerce Website

A modern and responsive **cattle marketplace website** built with **HTML, CSS, and JavaScript**. 🌾

## ✨ Features

* 🐄 Dairy cows, beef cattle, bulls & calves
* 🔎 Live search with auto-suggestions
* 🏷️ Product filtering by category & breed
* 💰 Price filtering & sorting
* 🛒 Shopping cart with quantity control
* ❤️ Wishlist functionality
* 💾 Cart & wishlist saved with Local Storage
* 🌙 Dark mode
* 🔔 Toast notifications
* 💳 Checkout & order summary
* 📱 Fully responsive design

## 🛠️ Technologies

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript
* 💾 Local Storage

## 🚀 How to Run

1. Open the project in VS Code.
2. Open `index.html`.
3. Run it directly in a browser or use **Live Server**.
4. Explore the marketplace and test the search, filters, cart & wishlist. 🛒
